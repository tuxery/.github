# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security reports.

Use GitHub Security Advisories when enabled on the affected repository, or contact the Tuxery maintainers privately through the organization.

## Scope

Security reports may concern:

- upstream source aggregation (Flathub, Snapcraft, AppImage, native packages)
- the package matching/deduplication engine
- secrets handling
- infrastructure and CI/CD
- organization-level GitHub configuration

We will acknowledge reports and coordinate remediation privately.
